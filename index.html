BP26 Glitch for After Effects

The BP26 Glitch Editor, as a native effect. Drop it on any layer, pick a color and a preset, and get the same glitch the web editor makes, live in your timeline. It can also split the glitch into 3D layers for camera moves.

Install · about 2 minutes

Install it once

On a Mac

  1. Download and unzip

    Click Download for Mac above and double-click the zip. You get a folder called BP26 Glitch for After Effects.

  2. Quit After Effects

    Save your project and quit After Effects. The installer won't run while it's open.

  3. Run the installer

    Double-click Install BP26 Glitch.command. A Terminal window opens and asks for your Mac password. Typing won't show any characters, so just type it and press Return.

    If macOS says it can't be opened because it's from an unidentified developer: open System Settings → Privacy & Security, scroll down, click Open Anyway, and double-click the installer again.

  4. Open After Effects

    You'll find the effect under Effect → BP26 → BP26 Glitch, and the helper panel under Window → BP26 Glitch Tools.jsx.

Installer blocked completely?

Open Terminal, type bash followed by a space, drag Install BP26 Glitch.command onto the Terminal window, and press Return. It does the same thing.

On Windows

  1. Download and extract

    Click Download for Windows above, right-click the zip and choose Extract All. Don't run anything from inside the zip.

  2. Close After Effects

    Save your project and close After Effects.

  3. Run the installer

    Double-click Install BP26 Glitch.bat and click Yes when Windows asks for administrator rights. If a blue Windows protected your PC box appears, click More info → Run anyway.

  4. Open After Effects

    The effect is under Effect → BP26 → BP26 Glitch and the panel under Window → BP26 Glitch Tools.jsx, same as on a Mac.

Use

Make your first glitch

  1. Apply the effect

    Select an image, video or precomp layer and choose Effect → BP26 → BP26 Glitch. It opens on P1, Purple and Even lighting, the same defaults as the web editor.

  2. Set the base look

    In Color & Light, pick the color and lighting. For buildings, try Arch.

    Purple Blue Green White Yellow Pink

    Purple, Blue and Green are the speaker colors. Yellow and Pink are for media and press textures.

  3. Shape the glitch

    In Glitch, choose a Preset, then use Amount to make it lighter or heavier. Click New Variation until the layout feels right. Each Variation number always gives the same layout, so you can come back to it.

  4. Animate (optional)

    Open Motion and tick Animate. The glitch moves on its own; Speed sets the pace. P3 is tuned for slower motion.

3D

Fly a camera through the glitch

The glitch can be split into depth layers: the base image at the back, the tears in layers in front of it, the smears in front of those, and the headshot closest to camera. Straight on it looks exactly like the flat effect. Move the camera and the pieces separate.

  1. Finish the 2D look first

    Set the color, preset and variation on your layer.

  2. Make the stack

    Open Window → BP26 Glitch Tools.jsx, select the layer and click Make 3D Stack. You get one layer per depth group, all controlled by your original layer.

  3. Add a camera and move it

    Click Add Camera for a camera that starts straight on, then animate it like any AE camera.

  4. Tune the depth

    In the effect's 3D Stack group: Depth Spread (total depth), Depth Randomness, Drift and Drift Speed (pieces float in Z), Headshot Depth. Changed Depth Layers? Click Make 3D Stack again.

Keep editing the original layer. The extra layers copy its settings automatically. Flatten Stack turns it back into one layer.

Updates

Getting a new version

New versions come from the same buttons at the top of this page. Download again and run the installer again (Install BP26 Glitch.command on a Mac, Install BP26 Glitch.bat on Windows). It replaces the old version, and your projects keep their settings.

To remove it completely, run the Uninstall BP26 Glitch file from the same folder.

Troubleshooting

If something's off

The effect isn't in the Effect menu

Quit After Effects completely and reopen it; new plug-ins load at launch. Make sure the installer finished with a ✓ (Mac) or OK (Windows) next to your After Effects version.

Colors don't match the web editor

Your project's color management converts the footage first. In File → Project Settings → Color, set Working Space to None or sRGB.

The streaks are too long

Lower Smear Length, or use fewer Smears.

The 3D stack feels slow

Each depth layer renders the effect once. Lower Depth Layers (4 is often enough) and click Make 3D Stack again, or preview at half resolution.

Windows: the effect doesn't show up

Check that the installer printed OK next to your After Effects version. The plug-in lives in Program Files\Adobe\Adobe After Effects 20xx\Support Files\Plug-ins\BP26. If your After Effects is installed somewhere else, copy BP26 Glitch.aex into that version's Support Files\Plug-ins folder yourself.
